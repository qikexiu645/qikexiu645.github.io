💡 一点理论：什么是全栈 & 前后端分离？

全栈开发：一个人（或一个团队）能同时搞定前端、后端、数据库、部署，对整个项目有全局掌控力。

前后端分离：前端负责”长什么样、怎么交互”，后端负责”数据怎么存、逻辑怎么跑”，两者通过 API 接口 用 JSON 格式通信。

简单比喻：后端是厨房（做菜），前端是大堂（摆盘上菜），接口就是传菜窗口 🍜

1️⃣ 安装 Python（3.12 版本）

Step 1：下载安装包

去 Python 官网 https://www.python.org/downloads/ 下载 Python 3.12.x 的 Windows installer（64位）。

Step 2：安装（⚠️ 重点！）

双击安装包，一定要勾选这两个选项：

  • ✅ Use admin privileges when installing py.exe
  • ✅ Add python.exe to PATH

然后点击 Customize installation → 进入高级选项。

在高级选项中：

  • 勾选所有可选功能
  • 安装路径不要选 Program Files（建议 C:\Python312 或 D:\Python312）
  • 点击 Install
