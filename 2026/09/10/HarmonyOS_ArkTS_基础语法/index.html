鸿蒙应用开发（ArkTS）基础语法讲解

说明：鸿蒙（HarmonyOS）应用开发官方主推语言是 ArkTS，它在 TypeScript 的基础上做了扩展与约束，专为声明式 UI 设计。本文所有语法均以 ArkTS为准。

学习前提：已安装 DevEco Studio，能创建一个空的 Stage 模型工程。

一、基础数据类型

ArkTS 是强类型语言，变量必须有明确的类型。三种最核心的基础类型如下：

类型 关键字 用途 示例
字符串 string 描述信息、文本 "你好鸿蒙"
数字 number 计算、数值 100、3.14
布尔 boolean 判断真假 true、false

1.1 string 字符串：描述信息

用来存放文字、描述性信息。可以用 双引号 或 单引号，推荐使用双引号。

重点提示：

  • 用 `${变量}` 的方式（模板字符串）可以在字符串中直接嵌入变量，开发中最常用。
  • ArkTS 中类型必须匹配，不能把数字直接赋值给字符串变量。

1.3 boolean 布尔：判断（真、假）

只有两个值：true（真）、false（假）。主要用于条件判断。

比较符号速记：

符号 含义
> / < 大于 / 小于
>= / <= 大于等于 / 小于等于
=== 严格相等（值、类型都相同）
!== 不相等

⚠️ 推荐始终使用 === 和 !==，避免使用 ==（会做类型转换，容易出错）。

二、常量的定义

常量使用 const 关键字定义，一旦赋值就不能再修改。

let vs const 如何选择？

关键字 含义 是否可修改 使用场景
let 变量 ✅ 可修改 值会变化的（如计数、分数）
const 常量 ❌ 不可修改 值固定不变（如配置、PI）

最佳实践：默认优先用 const，只有当确定值需要修改时才改用 let，这样可以避免意外修改带来的 bug。

三、数组

数组用来存放多个同类型的数据，用 类型[] 或 Array<类型> 声明。

数组小结：

5.5 箭头函数 vs 普通函数：如何选择？

场景 推荐
简单回调、数组操作 ✅ 箭头函数（简洁）
需要 this 动态绑定（类方法） ⚠️ 普通函数
UI 组件的事件回调 ✅ 箭头函数（最常见）
